# Minimal HPC examples for R and Python

This repository introduces running simulation studies on the GWDG High Performance Cluster, with small examples for R and Python notebooks.

Choose the guide for the operating system on **your own computer**:

1. [macOS guide](guides/macos.md)
2. [Linux guide](guides/linux.md)
3. [Windows guide](guides/windows.md)

Each guide walks through downloading the examples, setting up SSH, testing locally, uploading files, submitting Slurm jobs, checking their outcomes, and downloading results. Follow its numbered steps and choose **R** or **Python** when prompted; you only need one language.

The shared [R walkthrough](r/README.md) and [Python walkthrough](py/README.md) provide the language-specific steps, with local commands for all three operating systems. The Python walkthrough covers Positron, VS Code, and JupyterLab.

```text
guides/macos.md        macOS walkthrough
guides/linux.md        Linux walkthrough
```
